# Лабораторная работа №6 — Генерация отчётов

**Вариант 7.** Наследование, полиморфизм, интерфейсы и композиция.

## Задача

Реализовать `ReportService`, который формирует строки отчёта и передаёт их компоненту `Renderer`. Реализованы три взаимозаменяемых компонента: `TextRenderer`, `HtmlRenderer` и `MemoryRenderer`.

## Запуск

```bash
python main.py
python -m unittest discover -s tests -v
```

Python 3.10+, стандартная библиотека.

## Реализованные требования

- общий контракт `Renderer` на основе `abc.ABC`;
- три реализации с одинаковым интерфейсом;
- внедрение зависимости через конструктор;
- композиция: `ReportService` использует объект `Renderer`;
- тестовая реализация `MemoryRenderer`;
- проверки ошибок и замены реализации без изменения `ReportService`.
