# Лабораторная работа №3 — Процедурное программирование

**Вариант 1 — Посещаемость**

Программа:
- проверяет отметки посещаемости;
- рассчитывает процент посещаемости;
- определяет статус допуска;
- формирует рейтинг;
- фильтрует допущенных студентов;
- содержит автоматические тесты.

## Запуск

```bash
python main.py
```

## Тесты

```bash
python -m unittest discover -s tests -v
```
