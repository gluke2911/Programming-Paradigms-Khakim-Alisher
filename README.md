## Результаты

Для сквозной задачи во всех четырёх стилях результат: **228**.

Для варианта 20 используется набор:

`[2, 3, 4, 5, 8, 11, 13, 15, 17, 20, 23, 25]`

Простые числа:

`[2, 3, 5, 11, 13, 17, 23]`

Количество простых чисел: **7**.

## Сравнение подходов

- **Императивный:** явно изменяется состояние переменных и накопителей.
- **Процедурный:** алгоритм разделён на отдельные функции.
- **ООП:** данные и операции объединены в объекте `NumberAnalyzer`.
- **Функциональный:** используются функции-предикаты и преобразования коллекции без явного цикла-накопителя.
- **Событийный:** вычисление запускается обработчиком нажатия кнопки.

Подробный отчёт с теорией, исходным кодом, результатами, сравнительной таблицей, ответами на контрольные вопросы и выводом находится в `report/`.
