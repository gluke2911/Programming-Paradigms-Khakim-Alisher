# Лабораторная работа №5 — Расписание аудиторий

**Вариант 7.** Классы, объекты и инкапсуляция.

## Задача

Реализовать классы `Lesson` и `ClassroomSchedule`. Расписание должно добавлять занятия и запрещать пересечение занятий в одной аудитории. Проверки выполняются до изменения состояния.

## Запуск

```bash
python main.py
python -m unittest discover -s tests -v
```

Python 3.10+, стандартная библиотека.

## Реализованные требования

- два взаимодействующих класса;
- проверка времени и обязательных полей;
- защита внутренней коллекции занятий;
- добавление только через публичный метод `add_lesson`;
- запрет пересечения занятий в одной аудитории;
- автоматические тесты, включая ошибочные сценарии.
