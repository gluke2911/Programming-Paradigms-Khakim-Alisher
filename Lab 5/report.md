## 1. Цель работы

Изучить создание классов и объектов, применение инкапсуляции, проверку инвариантов и изменение состояния объектов через публичный интерфейс.

## 2. Постановка задачи

Разработать классы `Lesson` и `ClassroomSchedule`. Класс `Lesson` хранит название занятия, аудиторию и время начала и окончания. Класс `ClassroomSchedule` управляет списком занятий. При добавлении необходимо запрещать пересечение занятий в одной аудитории. Занятия в разных аудиториях могут проходить одновременно, а занятия в одной аудитории могут идти подряд без временного разрыва.

## 3. Алгоритм работы

1. Создаётся объект `ClassroomSchedule`.
2. Для каждого занятия создаётся объект `Lesson`.
3. При создании `Lesson` проверяются название, аудитория и корректность временного интервала.
4. Метод `add_lesson` сравнивает новое занятие с уже существующими.
5. Если аудитория совпадает и интервалы пересекаются, выбрасывается `ValueError`.
6. Если конфликтов нет, занятие добавляется в расписание.
7. Для чтения списка занятий предоставляется свойство `lessons`, возвращающее кортеж.

## 4. Описание классов

| Класс | Ответственность | Основные данные и методы | Инварианты |
|---|---|---|---|
| `Lesson` | Хранение данных об одном занятии | `title`, `classroom`, `start`, `end` | Название и аудитория не пусты; начало раньше окончания |
| `ClassroomSchedule` | Управление расписанием | `_lessons`, `lessons`, `add_lesson`, `find_by_classroom` | В одной аудитории нет пересекающихся занятий |

## 5. Инкапсуляция

Внутренний список `_lessons` хранится внутри `ClassroomSchedule`. Пользователь класса работает с расписанием через методы и свойство. Свойство `lessons` возвращает кортеж, поэтому клиентский код не может добавить или удалить занятия через полученное представление. Метод `add_lesson` проверяет данные до изменения состояния.

## 6. Тестирование

Автоматические тесты находятся в `tests/test_schedule.py`. Они проверяют:
- создание корректного занятия;
- запрет пустого названия;
- запрет нулевого или отрицательного временного интервала;
- разрешение занятий подряд;
- запрет пересечения в одной аудитории;
- разрешение одновременных занятий в разных аудиториях;
- невозможность изменять полученный кортеж занятий;
- отклонение объекта неподходящего типа.

Для запуска:

```bash
python -m unittest discover -s tests -v
```

## 7. Контрольные вопросы

1. **Что такое класс?** Класс — описание структуры и поведения объектов определённого типа.
2. **Что такое объект?** Объект — экземпляр класса с конкретными данными.
3. **Что такое атрибут?** Атрибут хранит данные объекта или класса.
4. **Что такое метод?** Метод — функция, определённая внутри класса.
5. **Что такое инкапсуляция?** Это объединение данных и методов и ограничение прямого доступа к внутреннему состоянию.
6. **Для чего используется `__init__`?** Для первоначальной настройки нового объекта.
7. **Что такое инвариант?** Условие, которое должно оставаться истинным для корректного состояния объекта.
8. **Зачем нужна валидация?** Чтобы отклонять некорректные данные до изменения состояния.
9. **Что означает `_lessons`?** Начальное подчёркивание обозначает внутренний атрибут, предназначенный для использования внутри реализации.
10. **Почему возвращается кортеж?** Кортеж не позволяет клиенту изменять коллекцию через публичное свойство.
11. **Зачем нужны исключения?** Они сообщают о недопустимых данных или действиях.
12. **Что проверяют автоматические тесты?** Корректные сценарии, граничные условия и обработку ошибок.
